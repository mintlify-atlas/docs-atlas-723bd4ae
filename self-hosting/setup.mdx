This page walks you through deploying CVR-MATE on your own infrastructure. You will clone the repository, configure environment variables, initialize the database schema, and start the application — either for local development or as a production Node.js service.

## Prerequisites

Before you begin, make sure the following are available on your system:

- **Node.js** — LTS release recommended
- **pnpm** — used as the package manager throughout the project
- **PostgreSQL** — a running database instance that CVR-MATE can connect to

## Installation

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/Nouman-Usman/CVR-MATE.git
    cd CVR-MATE
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    pnpm install
    ```
  </Step>

  <Step title="Configure environment variables">
    Copy the example file and fill in the required values.

    ```bash
    cp .env.example .env.local
    ```

    <Warning>
      CVR-MATE will not start correctly without the required environment variables. At minimum you need `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `CVR_API_KEY`, and `GEMINI_API_KEY`. See the [Environment Variables](/environment-variables) reference for the full list.
    </Warning>
  </Step>

  <Step title="Push the database schema">
    Apply the Drizzle schema to your PostgreSQL database. This is the recommended approach for first-time setup.

    ```bash
    pnpm db:push
    ```
  </Step>

  <Step title="Start the development server">
    ```bash
    pnpm dev
    ```

    The application is available at [http://localhost:3000](http://localhost:3000).
  </Step>

  <Step title="Build and start for production">
    ```bash
    pnpm build && pnpm start
    ```
  </Step>
</Steps>

## Available scripts

The following scripts are defined in `package.json`:

| Command | Description |
|---|---|
| `pnpm dev` | Start the Next.js development server |
| `pnpm build` | Build the application for production |
| `pnpm start` | Start the production server (requires a prior build) |
| `pnpm lint` | Run ESLint across the codebase |
| `pnpm db:generate` | Generate Drizzle migration artifacts from schema changes |
| `pnpm db:migrate` | Apply pending migrations to the database |
| `pnpm db:push` | Push the schema directly to the database (dev convenience) |
| `pnpm db:studio` | Open Drizzle Studio to browse and edit data |

## Deployment

CVR-MATE is a standard Next.js application that runs on the Node.js runtime. Deploy it to any host that supports Node.js — a VPS, a container platform, or a managed app service.

<Note>
  No Docker files or `vercel.json` are committed to this repository. There is no platform-specific deployment configuration; you are free to deploy to any Node.js-compatible host using your own preferred method.
</Note>

After deploying, configure your hosting environment to:

1. Provide all required environment variables.
2. Schedule the cron endpoints (see [Background jobs](/self-hosting/background-jobs)).
3. Point Stripe webhooks to `/api/stripe/webhook` on your domain.
