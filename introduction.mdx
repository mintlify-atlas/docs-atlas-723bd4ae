CVR-MATE is an automated B2B lead intelligence platform built for Danish sales teams. It connects directly to the Danish CVR registry — the authoritative source for all registered Danish companies — so you can search, monitor, and act on company data without switching between tools. Whether you're prospecting new accounts, tracking changes at existing customers, or scaling outreach across a pipeline, CVR-MATE brings the data and the workflow into a single application.

## Architecture overview

CVR-MATE is a Next.js 16 App Router application backed by PostgreSQL and deployed as a Node.js server. The application is organized into a small set of clear layers:

- **`app/`** — Next.js App Router pages and API route handlers
- **`components/`** — UI and feature components built with Tailwind CSS 4 and shadcn/ui
- **`db/`** — Drizzle ORM schema and database client
- **`lib/`** — Domain logic: auth, AI, CVR API client, cron scheduling, notifications, Stripe billing, i18n, and CRM adapters
- **`middleware.ts`** — Route protection and team invitation rate limiting

Key architectural patterns:

- **Server-Sent Events (SSE)** power the real-time notification stream at `/api/notifications/stream`. The current fan-out is in-process via `lib/notifications.ts`, which works for single-instance deployments. For horizontally scaled deployments, replace the fan-out with a shared Redis pub/sub channel.
- **Background jobs** run as secured API endpoints (`/api/cron/triggers`, `/api/cron/person-changes`) verified by Upstash QStash signatures, with a fallback `CRON_SECRET` bearer token for local development.
- **AI features** are powered by Google Gemini via `@google/generative-ai`. All AI endpoints include retry handling and rate-limit messaging.
